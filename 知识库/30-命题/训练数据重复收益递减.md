# 训练数据重复收益递减

## 命题

在固定模型容量下，持续增加训练 token 会进入收益递减区间；当新增 token 来自重复样本而非新增独立信息时，不能把“处理 token 数增加”直接等同于“有效数据规模等比例增加”。

这条命题不表示重复数据毫无价值，也不声称存在跨模型和语料固定不变的递减曲线。

## 两篇论文给出的边界

- Kaplan 的联合 $L(N,D)$ 模型显示，固定 $N$ 或固定 $D$ 而只扩大另一项时会进入收益递减，并用 early stopping 控制有限数据下的过拟合。
- Hoffmann 的主要缩放分析刻意限制在少于一个 epoch 的区域，因此其 $D\propto C^{0.5}$ 主要描述“多看新 token”的情形；论文明确把多 epoch 情形留给未来研究。
- Chinchilla 的 1.4T token 数据混合中，MassiveWeb 与 Wikipedia 子集实际超过一个 epoch，说明“总 token 数”“唯一 token 数”和“各子集重复率”必须分开记录。
