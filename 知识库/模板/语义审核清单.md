# 语义审核清单

新论文自动生成 `review_status: pending` 后，至少完成以下检查再改为 `reviewed`：

- [ ] 每个关键结论都有可打开的 PDF `#page=N` 证据，且页内文字确实支持该结论。
- [ ] `supports` 用于直接增信；不能因为“主题相关”就建立。
- [ ] `refines` 用于保留核心结论但修改精度、条件或适用范围。
- [ ] `challenges` 只用于可比条件下的不兼容证据；若条件不同，应先新增 `limited_by`。
- [ ] 概念口径一致，尤其检查参数是否含 embedding、$D$ 是唯一数据还是 tokens seen、$C$ 的 FLOPs 口径。
- [ ] Wiki 链接的显示文本不包含 `$...$`；需要公式时写成 `[[概念笔记|概念名称]] $N$`，避免 Obsidian 原样显示美元符号。
- [ ] Obsidian 数学语法使用 `$...$`（行内）或 `$$...$$`（独立公式块）；不使用 `\(...\)`、`\[...\]`，也不留下裸 LaTeX。
- [ ] 保留外推区间、模型族、数据分布、训练轮数、调度和评估指标等适用边界。
- [ ] 区分论文明确陈述的事实、由证据推导的推断、尚未验证的假设。
- [ ] 合并概念或废弃旧关系前由人工确认；旧关系先标记待审核，不直接删除。
