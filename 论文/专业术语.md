# 专业术语

本文件只维护需要跨论文统一、容易误译或需要决定是否保留英文的术语。

这里记录的是本项目已经确认的翻译策略，不是对“唯一正确译法”的宣称。术语应结合论文上下文使用，不能对公式、引用、代码、模型名或参考文献做机械替换。

## 默认规则

- 正文以中文为主。
- 本表中每个术语只有“英文”或“中文”两种策略，正文始终使用表内确定的唯一写法，不做中英并列。
- 未列入本表的模型名、数据集名、基准名、缩写、单位和公式变量默认保留原文，例如 Chinchilla、WebText2 和 MMLU。
- 英文与相邻中文之间留一个半角空格。
- 同一个英文词在不同上下文含义不同时，按语义翻译，不做全局字符串替换。

## 维护方法

1. 新论文开始翻译前，先从标题、摘要和正文中提取高频专业词。
2. 只添加会重复出现、容易误译或确实需要保留英文的词；模型名和数据集名不必逐项登记。
3. 在“英文”和“中文”中确定一种策略，并记录唯一写法和必要的上下文说明。
4. 译文完成后检查同一术语是否出现多个译法。
5. 修改本表只影响后续翻译与修订；已经生成的 PDF 不会自动变化。
