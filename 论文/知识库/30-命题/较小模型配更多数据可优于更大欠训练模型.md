# 较小模型配更多数据可优于更大欠训练模型

## 命题

在近似相同的预训练计算量下，70B 参数、训练 1.4T token 的 Chinchilla 整体优于 280B 参数、训练约 300B token 的 Gopher。这说明参数更多并不自动意味着固定预算下性能更好；若大模型读取的数据不足，它可能位于 [[计算最优前沿]] 的低效一侧。

## 证据强度

- **大规模实证：** Chinchilla 在 The Pile 各子集、MMLU、阅读理解、常识和闭卷问答等评估上广泛优于 Gopher，同时参数量小四倍，推理与微调成本更低。
- **较干净的小规模对照：** 在 $10^{21}$ FLOPs 下，Hoffmann 训练 2.80B 与 4.74B 两个相近架构模型；前者是其方法预测的最优规模，最终损失优于 Kaplan 公式预测的更大模型。
- **保留项：** Chinchilla 与 Gopher 还更换了 AdamW、tokenizer 和数据混合比例，故单次大模型比较不能把全部差异唯一归因于 $N,D$。
