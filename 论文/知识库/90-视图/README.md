# 知识库视图说明

## 两类 Canvas 的边界

- `Scaling Laws 知识串联.canvas` 是**人工专题图**：用带方向和关系标签的边，表达“问题 → 论文 → 共同结论 → 定量分歧 → 方法解释 → 实证 → 边界”。同步程序不覆盖它，避免破坏人工选择与排版。
- `自动论文总览.canvas` 是**自动派生图**：由同步程序根据论文入口笔记重建。新论文或 PDF 版本变化时可以更新，不应在其中保留人工排版。

## 其他视图

- `知识库索引.base` 是动态查询，会随笔记属性自动更新；包含“全部知识”、“论文”、“命题”和“待审核”视图，并排除模板与本视图目录。
- Obsidian 全局 Graph 根据 Markdown 内部链接自动变化，适合发现聚类、孤立知识与跨论文关系；它不承担复杂论证的精确表达。

## 使用规则

1. 需要讲清“为什么”时，使用人工专题图。
2. 需要查看“现在有哪些论文”时，使用自动总览或 Bases。
3. 需要检查链接结构时，使用 Graph 或当前笔记的 Local Graph。
