# 固定计算预算与训练条件

## 边界

两篇论文回答的是**固定预训练计算预算、以语言模型损失为目标**时的配置选择。它们没有证明在参数预算、墙钟时间、显存、推理延迟或总生命周期成本固定时仍有完全相同的最优解。

## 条件清单

1. 模型主要是稠密、decoder-only、autoregressive Transformer；稀疏 MoE、检索增强或不同模态会改变每参数/每 token 的效用。
2. 一阶计算近似为 $C\approx6ND$，但上下文注意力、embedding、激活重算和硬件利用率会改变实际成本。
3. 学习率调度必须与目标训练时长匹配。Hoffmann 的核心方法修正之一，就是避免用过长余弦周期的中间损失评估短训练配置。
4. batch size、优化器和 early stopping 的定义参与前沿估计；Kaplan 的 $C_{min}$ 还显式校正 critical batch size。
5. 优化目标是 [[交叉熵损失 L]]。若加入推理成本，较小模型的优势可能扩大；若目标是特定下游能力，最优点则需重新测量。
